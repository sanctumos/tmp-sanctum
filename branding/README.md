# Branding pack

Shared SanctumOS tokens for **tmp.sanctumos.org** (web) and **Sanctum Share** (Android).

| File | Role |
|------|------|
| `tokens.json` | Canonical names + hex colors + path map |
| `../public/branding/` | Live web assets (deployed with `public/`) |
| `../android/app/src/main/res/…` | Android colors / strings / mark |

**How to rebrand:** [`docs/BRANDING.md`](../docs/BRANDING.md)
