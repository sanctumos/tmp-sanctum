# Sanctum Share (Android)

SanctumOS-branded share-sheet client for Sanctum Temp.

Full docs: **[`docs/ANDROID.md`](../docs/ANDROID.md)** · Branding: **[`docs/BRANDING.md`](../docs/BRANDING.md)**

```bash
export JAVA_HOME=/path/to/jdk-17
cd android
./tools/assemble-debug-on-termux.sh   # aarch64 Termux/Proot
# or: ./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
